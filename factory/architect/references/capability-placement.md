# Capability Placement

## Skill
Use when the model must repeatedly make contextual judgments or follow a reusable workflow.

## Script
Use when the same transformation, validation, parsing, packaging, or calculation should produce deterministic results.

## Reference
Use for detailed domain knowledge, rubrics, policies, or examples that should not occupy SKILL.md on every activation.

## Asset
Use for visual examples, templates, seed files, source artifacts, or other non-instructional inputs.

## Tool / API
Use for live data, external systems, repository mutations, or capabilities requiring credentials.

## Do not skillize
Do not create a Skill only to restate generic model abilities or a one-time prompt.
