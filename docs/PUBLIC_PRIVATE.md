# Public / Private Model

## Public

A public Skill must be self-contained and must not contain or depend on secrets, confidential company/client data, private repository references, or private assets.

## Private

A private Skill may use confidential context and examples as long as they remain inside the private repository and are appropriate for that repository's users.

## Publication

Publishing creates a new public variant. It does not simply change repository visibility or move private files wholesale.
